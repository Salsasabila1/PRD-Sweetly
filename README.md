# PRD-Sweetly
# Product Requirements Document (PRD)

## Aplikasi Resep Dessert Sederhana

### 1. Latar Belakang

Banyak orang ingin membuat dessert di rumah, tetapi sering kesulitan menemukan resep yang mudah, praktis, dan sesuai bahan yang tersedia. Aplikasi ini bertujuan menyediakan kumpulan resep dessert sederhana yang mudah diikuti oleh pemula.

### 2. Tujuan Produk

* Menyediakan resep dessert yang mudah dan cepat dibuat
* Membantu pengguna menemukan resep berdasarkan bahan yang dimiliki
* Memberikan panduan langkah demi langkah yang jelas

### 3. Target Pengguna

* Pemula yang baru belajar memasak
* Mahasiswa atau pekerja yang ingin membuat dessert praktis
* Pengguna yang memiliki keterbatasan bahan

### 4. Fitur Utama

1. **Daftar Resep**

   * Menampilkan berbagai resep dessert
   * Kategori (kue, minuman manis, puding, dll)

2. **Detail Resep**

   * Nama makanan
   * Gambar
   * Bahan-bahan
   * Langkah pembuatan

3. **Pencarian Resep**

   * Cari berdasarkan nama atau bahan

4. **Favorit**

   * Simpan resep yang disukai

5. **Filter Sederhana**

   * Berdasarkan waktu memasak atau jumlah bahan

### 5. User Flow

1. Pengguna membuka aplikasi
2. Melihat daftar resep
3. Memilih salah satu resep
4. Membaca detail dan langkah pembuatan
5. Menyimpan ke favorit (opsional)

### 6. Kebutuhan Fungsional

* Aplikasi dapat menampilkan daftar resep
* Aplikasi dapat menampilkan detail resep
* Aplikasi dapat menyimpan data favorit

### 7. Kebutuhan Non-Fungsional

* UI sederhana dan mudah digunakan
* Dapat berjalan di perangkat Android

### 8. Platform

* Mobile (Android – Flutter)

### 9. Metode Pengembangan

* Menggunakan Flutter
* Data awal menggunakan lokal (JSON atau hardcoded)

### 10. Timeline Sederhana

* Minggu 1: Desain UI
* Minggu 2: Implementasi fitur utama
* Minggu 3: Testing dan perbaikan

### 11. Risiko

* Data resep terbatas

### 12. Keberhasilan Produk

* Aplikasi berjalan tanpa error
* Pengguna dapat menemukan dan mengikuti resep dengan mudah
* Minimal memiliki 10+ resep dessert

---

PRD ini dirancang sederhana untuk kebutuhan tugas atau pengembangan awal aplikasi.
